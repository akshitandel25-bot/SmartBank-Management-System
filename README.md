# SmartBank Management and Fraud Detection System

## About the Project

SmartBank is a Java Swing-based banking management application integrated with a PHP API and MariaDB/MySQL database. It demonstrates banking operations, transaction management, fraud monitoring, and expense control.

## Technologies Used

- Java Swing
- PHP
- MariaDB / MySQL
- XAMPP
- GitHub

## Features

- Customer and Manager Login
- Deposit and Withdrawal
- Fund Transfers
- Transaction History
- Fraud Detection and Security Center
- Smart Insights
- SmartSpend Budget and Expense Tracking
- Monthly Expense Reports
- Manager Dashboard

## Project Structure

- `java/` — Java application source code
- `php/` — PHP API endpoints
- `database/` — SQL scripts for database setup

## Requirements

- Java Development Kit (JDK)
- XAMPP
- MariaDB / MySQL
- A Java-compatible IDE, such as Visual Studio Code

## How to Run

1. Install the required Java JDK and XAMPP.
2. Import the provided SQL setup script into MariaDB/MySQL using phpMyAdmin.
3. Configure the PHP database connection using your local credentials.
4. Place the PHP API folder inside the XAMPP `htdocs` directory.
5. Start Apache and MariaDB/MySQL in XAMPP.
6. Configure the API URL in the Java application.
7. Compile and run the Java application.

## Security

Use test data only. Never publish database passwords, API keys, or real customer banking information.

## Project Type

Academic Java microproject demonstrating application development, database connectivity, transaction management, and basic banking security concepts.
